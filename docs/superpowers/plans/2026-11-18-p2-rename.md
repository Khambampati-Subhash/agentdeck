# P2 Rename to AgentDeck Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** AgentDeck and stock Herdr run side by side on one Mac without seeing each other's terminals, settings or core.

**Architecture:** One `brand.rs` of `const`s per half. Every name that collides with Herdr or that users see is read from it; internal names stay upstream's. Install, migration and the checks are our own scripts outside upstream code.

**Tech Stack:** Rust (both halves), bash and Python 3 stdlib scripts, `just`.

**Spec:** `docs/superpowers/specs/2026-11-18-p2-rename-design.md`

## Global Constraints

- Names (from the spec, verbatim): app binary `agentdeck`; core binary `agentdeck-core`, CLI `adk`; app home `~/.config/agentdeck`; core dirs `agentdeck-core` under config, state and runtime; Windows pipe prefix `agentdeck-core-<user>-`; control socket `agentdeck.sock`; bundle ids `io.github.khambampati-subhash.agentdeck` and `io.github.khambampati-subhash.agentdeck.core`; launchd temp jobs `/tmp/adk-launchd-*`; mod import `"agentdeck"` with `"herdr"` kept as an alias; `TERM_PROGRAM=agentdeck`.
- Variables read: `AGENTDECK_HOME`, `AGENTDECK_APP_ID`, `ADK_SESSION`, `ADK_SOCKET`, `ADK_TERMINAL_ID`, `ADK_TERMINAL_SOCKET`. The old names (`HERDR_APP_HOME`, `HERDR_APP_ID`, `HC_SESSION`, `HC_SOCKET`, `HC_TERMINAL_ID`, `HC_TERMINAL_SOCKET`) are never read as a fallback.
- Pane env: `ADK_SESSION`, `ADK_TERMINAL_ID`, `ADK_TERMINAL_SOCKET`, plus `HC_TERMINAL_ID` (same value). Never `HC_SESSION` or `HC_TERMINAL_SOCKET`.
- Unchanged: labels (`herdr.space`, ...), the core document key `"herdr-app"`, crate and module names, keymap contexts, the `--hc-launchd` sentinel, OSC 7501, internal knobs (`HC_QUIET_MS`, `HC_LAUNCHD_*`, `HC_INSTALL_DIR`, `HC_UPDATE_*`, `HERDR_APP_LOG`, `HERDR_TEST_*`, ...) and P1's inert variables.
- Tests and manual runs use a sandbox `HOME` or `AGENTDECK_HOME`/`ADK_SESSION` under `/var/tmp`. Never touch `~/.config/herdr-app`, the default Herdr session, or the `agentos` core. Stop only cores you started. No live agents; fixtures only (`core/crates/herdr-core/tests/fake_tui.py`).
- Every upstream file changed is listed in `docs/upstream.md` (Task 8).
- Commits: conventional, lowercase, `app:`/`core:`/`repo:`, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- After a rebuild, the first core test run can time out on macOS (first-launch scan). Rerun before debugging.

## Review Focus

1. **AgentDeck started inside a stock Herdr pane** (`HC_SESSION`, `HC_TERMINAL_ID`, `HC_TERMINAL_SOCKET` all set): it must use its own core and not treat the Herdr terminal as its own. Pinned in Task 1 (paths) and Task 2 (client).
2. **Stock `hc` run inside an AgentDeck pane:** must not find or start a core named after AgentDeck's session in Herdr's dirs. Pinned in Task 2 (pane env lacks `HC_SESSION` and `HC_TERMINAL_SOCKET`).
3. **A mod's `hc([...])` call on a Mac with stock Herdr installed:** must reach AgentDeck's core, not the `hc` on `PATH`. Pinned in Task 4.
4. **A user mod importing `"herdr"`** (every shipped and shared mod today): must still load and get the same API. Pinned in Task 4.
5. **Migration over an existing AgentDeck home, or from a missing source:** must refuse without `--force`, never write before confirmation, never touch the source. Pinned in Task 6.
